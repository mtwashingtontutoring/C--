# Intro to C++

A beginner-friendly introduction to programming in C++. Students work on a
Debian Linux computer, write code in VSCodium, and keep all of their work in
Git and GitHub from the very first week.

## Who this is for

Students with little or no programming experience. Comfort using a mouse,
keyboard, and web browser is all that's assumed.

## Course outline

| # | Lesson | You will be able to... |
|---|--------|------------------------|
| 1 | [Setting Up Your Environment](lesson-01-environment-setup/README.md) | Install a compiler and VSCodium on Debian, then compile and run "Hello, World!" |
| 2 | [Git and GitHub](lesson-02-git-github/README.md) | Track your code with Git, publish it on GitHub, and submit work from there |
| 3 | [ASCII Art](lesson-03-ascii-art/README.md) | Use `cout`, `cin`, loops, and nested loops to draw shapes in the terminal |

## How each lesson is organized

- **Goals** - what you should be able to do by the end.
- **Walkthrough** - follow along, typing every command yourself.
- **Checkpoints** - stop and verify before moving on.
- **Exercises** - practice on your own.

## Conventions used in the guides

- Lines starting with `$` are typed in a terminal. Don't type the `$` itself.
- `sudo` runs a command as administrator and will ask for *your* password.
  Nothing appears on screen while you type the password - that's normal.
- Text in `<angle brackets>` is a placeholder - replace it with your own value,
  e.g. `<your-username>` becomes `jsmith`.
